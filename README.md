## ✨ О проекте

Это моё персональное портфолио, созданное с нуля на чистом **HTML, CSS и JavaScript**. Здесь я собрал свои работы, навыки и контакты. Сайт полностью адаптивен, работает без фреймворков и использует современные веб-технологии.

### 🎯 Что внутри

- 🎨 **Уникальный дизайн** — фиолетовая цветовая схема, эффект стекла (glassmorphism)
- 🌌 **Анимированный фон** — градиент + плавающие блобы + мерцающие звёзды + частицы
- 🪪 **Бейджик с верёвкой** — реагирует на движение мышки (физика маятника) и дёргается при клике
- 🎵 **Генератор случайной музыки** — прямо в браузере, без аудиофайлов
- 🌗 **Тёмная/светлая тема** — с сохранением выбора пользователя
- 🌐 **Мультиязычность** — русский и английский
- ✨ **Плавные анимации** — появление секций при скролле (AOS)
- 🖱️ **Кастомный курсор** — светящаяся точка + кольцо
- 📊 **Прогресс скролла** — полоска сверху
- ⬆️ **Кнопка «Наверх»** — плавный возврат
- 📱 **Адаптивность** — отлично смотрится на телефонах

🎨 Кастомизация

Изменить цвета

В style.css найдите блок :root и поменяйте переменные:

```css
:root {
    --accent: #a855f7;      /* Основной акцент */
    --accent-light: #d8b4fe; /* Светлый акцент */
    --bg-color: #0d0518;    /* Фон */
}
```

Изменить музыку

В script.js найдите массив PENTATONIC — это набор нот. Можно заменить на другие.

Добавить проект

В index.html найдите секцию id="projects" и скопируйте блок .project-card, поменяв картинку и текст.
